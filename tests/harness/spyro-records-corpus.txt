# Corpus for tests/harness/check_spyro_records.sh (the multi-Spyro sub-tick harness).
#
# Every case runs the spyro-coop mod headless with the players setting pinned
# and asserts the OPENPETE_SPYRO_RECDBG epoch line at the case frame: the hook
# call counts per feeder (model / shadow / flame) on that canonical tick, zero
# byte mismatches between the last hook's bytes and the DIRECT ring, zero
# speculative refusals, one epoch per VBL. The intermediate leg asserts the
# per-record lines (model count and pairing index, shadow and flame counts
# and bindings).
#
# Fields (pipe-separated):
#   name       case id
#   bk2        movie under games/spyro-1/bk2/ (its .args sidecar supplies
#              --skip-to-level); `level:<name>` boots --skip-to-level with no
#              movie (idle dragons)
#   players    the mod's players setting written to its settings.txt
#   frame      VBL of the canonical capture (the RECDBG epoch line asserted)
#   m|s|f      expected model / shadow / flame hook calls on that tick
#   pairs      expected previous-record index per model record, in hook-call
#              order, `-` = unpaired, `?` = unasserted (a case with no drawn
#              record has nothing to pair)
#   note
#   args       optional 10th field: extra launch args (`--runahead N` rows
#              exercise the led lists, P7)
#
# Measured 2026-09-14 (P0). Extra dragons draw FIRST, the composer's own
# player-1 call LAST (coop_draw.c); the mod draws no shadow for a gliding
# extra dragon, so the glide case has one shadow call for four models.
#
