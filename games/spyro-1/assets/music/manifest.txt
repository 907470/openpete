# openpete music override manifest — Spyro the Dragon
# ====================================================
#
# Drop PCM WAV files in this directory and they play in place of the
# disc's XA-ADPCM music. Two ways to name them:
#
#   1. Filename convention (no manifest needed): track_NN.wav, where
#      NN is the zero-padded track index from the table below.
#   2. A manifest entry here: `<track-index>  <file.wav>` (path is
#      relative to this directory). Manifest entries take precedence
#      over track_NN.wav.
#
# Lines starting with '#' are ignored. If a referenced file is
# missing, that track quietly falls back to the disc's original XA
# audio — partial coverage is fine, and you don't need to remove or
# comment entries whose files don't exist yet.
#
# Supported WAV format: PCM int16, mono or stereo, at 11025 / 22050 /
# 32000 / 44100 / 48000 Hz. Convert anything with ffmpeg:
#
#   ffmpeg -i input.flac -ac 2 -ar 44100 -sample_fmt s16 track_00.wav
#
# The disc image is still required — this only replaces music.
#
